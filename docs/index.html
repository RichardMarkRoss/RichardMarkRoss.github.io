Aimllama ↗

Keyboard and mouse for mobile shooters, without an emulator. The real game runs on your real phone. Aimllama mirrors it to your PC, or maps input on the device itself, and turns your keys into touches.

  • Real-time core in Rust. It streams the phone over ADB (scrcpy), upscales on the GPU and injects multi-pointer touch events over the control socket. I chose Rust so there are no GC pauses in the input path.
  • Vision engine. On-screen buttons jitter, so it re-finds them before each tap. Each search covers a tiny region instead of the whole frame, which keeps it cheap at 60–120 fps.
  • One product across three codebases. A Kotlin/Compose Android app shares the Rust core through the NDK. Play purchases are validated server-side in Firebase, and a QR handshake links a purchase to the desktop.

~16k lines of Rust · ~12k lines of Kotlin · Windows installer and in-app updates

Lotto Dash ↗

A South African lottery app on Google Play. Point your camera at a paper ticket and it checks every board against the latest draw in about five seconds. It covers all 7 games and sends push alerts when results land.

  • OCR ticket parser. ML Kit returns loose lines of text. I use the Y-coordinates of the dashed separator rows to split each ticket into header, numbers and footer, then detect the game and validate the receipt before trusting a single number.
  • Offline-first. Ticket changes apply optimistically on the device and queue while offline. The queue drains on the next app resume, so no scan is ever lost to a bad signal.
  • Backend of about 25 Cloud Function modules. Nightly result polling for each game, server-verified Play subscriptions, referrals and FCM. I moved it onto the new national lottery operator for 1 June 2026 and carried every user's saved tickets over.

140+ commits across the app and backend · subscriptions, ads and referrals

  • Flutter
  • Dart
  • ML Kit
  • Firebase
  • Cloud Functions (TS)
  • Firestore

Heroes Without Sound ↗

In competitive shooters, footsteps and gunfire carry information. Deaf and hard-of-hearing players don't get it. Heroes Without Sound is a Windows overlay that turns game audio into a 3D sphere-and-ring display showing where a sound came from, how far away it was and how loud.

  • Designed for a glance. Direction, distance and intensity have to read in a split second mid-fight, without covering the crosshair.
  • Launch site built in Next.js 16 with a React Three Fiber particle sphere that previews the overlay. I kept it on patched releases through the React Server Components CVE.

v0.1.0 Windows installer available · tested in Rainbow Six Siege

  • Next.js
  • React Three Fiber
  • Three.js
  • Tailwind
  • Vercel
